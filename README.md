# Cyberpunk Neon Radio Buttons

A **futuristic cyberpunk-inspired radio button UI** built with pure **HTML and CSS**. This interactive component features glowing neon effects, hover animations, and floating sparks, perfect for modern dashboards, gaming interfaces, and creative web projects.

---

## 🌟 Features

* Bright **neon cyan glow** for the selected button
* Smooth **hover and pressed animations**
* **Floating sparks** for a dynamic, futuristic effect
* **Light sweep** animation on hover
* Fully **interactive and responsive**
* Easy to integrate into any web project

---
 
## 🛠️ Usage

1. Clone this repository:

```bash
git clone https://github.com/TineshChasiya/Neon-Cyberpunk-Radio-Switch.git
```

2. Open the `index.html` file in your browser.

3. Copy the HTML and CSS into your own project if needed:

```html
<div class="radio-input">
  <label class="label">
    <input type="radio" name="value-radio"/>
    <span class="text">Play</span>
    <span class="spark"></span>
    <span class="spark"></span>
  </label>
  <label class="label">
    <input type="radio" name="value-radio"/>
    <span class="text">Stop</span>
    <span class="spark"></span>
    <span class="spark"></span>
  </label>
  <label class="label">
    <input type="radio" name="value-radio"/>
    <span class="text">Reset</span>
    <span class="spark"></span>
    <span class="spark"></span>
  </label>
</div>
```

---

## ⚡ CSS Styling

Make sure to include the full updated CSS from your project.

---

## 💡 Notes

* This UI component is built **purely with HTML and CSS**, no JavaScript required.
* Works best in **modern browsers** that support CSS pseudo-class `:has()` (for the selected button effect).
